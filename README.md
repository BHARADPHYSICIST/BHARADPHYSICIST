## 🧪 Research Projects

### 1. Unsupervised Segmentation of 21-cm EoR Data
Exploring label-free image-processing techniques to identify ionized regions in simulated 21-cm brightness temperature cubes.

**Methods:** Local entropy filtering, FFT filtering, thresholding, morphological operations, and watershed segmentation.

### 2. Galactic Rotation Curve Using the HI 21-cm Line
An experimental radio astronomy project focused on observing neutral hydrogen emission and investigating Galactic rotation through Doppler spectroscopy.

### 3. Double-Ridged Horn Antenna Design
Electromagnetic modelling and simulation of a double-ridged horn antenna using CST Studio Suite.
